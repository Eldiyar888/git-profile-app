# Git Profile App

Это приложение для отображения профиля пользователя с GitHub, использующее GitHub OAuth для аутентификации и получения данных профиля.

## Стек технологий

- **Frontend**: React, Ant Design, Axios, React Router.
- **Backend**: Express.js.
- **State management**: Redux Toolkit.

## Зависимости

### Внешние зависимости:

1. `axios` — для запросов к API.
2. `react` — библиотека для создания пользовательского интерфейса.
3. `react-router-dom` — для маршрутизации.
4. `redux-toolkit` — для управления состоянием.
5. `express` — для создания бэкенда.

### Для разработки:

1. `eslint` — для статического анализа кода.
2. `prettier` — для форматирования кода.

## Установка и запуск

### 1. Клонирование репозитория

Для начала, клонируйте репозиторий на вашу машину:

```bash
git clone https://github.com/Eldiyar888/git-profile-app.git
```

### 2. Установка зависимостей

#### Для фронтенда: 

Перейдите в директорию проекта и установите все зависимости:

```bash
cd git-profile-app
npm install
```

или, если используете yarn:

```bash
yarn install
```

#### Для сервера 

Для этого перейдите в папку server:

```bash
 cd server
 npm install
```

или, если используете yarn:

```bash
yarn install
```



### 3. Настройка переменных окружения

Для работы проекта необходимо создать OAuth приложение на GitHub и получить `Client ID` и `Client Secret`.

Для удобства, в репозитории уже добавлены примеры файлов конфигурации .env.example, которые можно использовать для настройки.

#### Для фронтенда:

Создайте файл .env в корне проекта и добавьте следующие переменные, подставив свои реальные значения, которые вы получите в настройках GitHub OAuth приложения:

```bash
VITE_CLIENT_ID=ваш_клиент_id_от_GitHub
VITE_REDIRECT_URI=http://localhost:5173/callback
```

#### Для сервера:

Для этого перейдите в папку server:

```bash
 cd server
```

затем создайте файл `.env` и добавьте следующие переменные:

```bash
CLIENT_ID=ваш_клиент_id_от_GitHub
CLIENT_SECRET=ваш_секретный_ключ_от_GitHub
```

### 4. Запуск фронтенда

Запустите фронтенд-приложение:

```bash
npm run dev
```

или:

```bash
yarn run dev
```

После этого приложение будет доступно по адресу [http://localhost:5173](http://localhost:5173).

### 5. Запуск серверной части

Для работы приложения необходим сервер для обработки аутентификации. Откройте папку `server` и выполните следующие команды:

1. Перейдите в папку `server`:

   ```bash
   cd server
   ```

2. Установите зависимости для серверной части:

   ```bash
   npm install
   ```

3. Запустите сервер:

   ```bash
   npm run dev
   ```

После этого сервер будет доступен по адресу [http://localhost:4000](http://localhost:4000).

### 6. Проверка

Теперь, когда все части запущены, перейдите в браузер и откройте [http://localhost:5173](http://localhost:5173). После аутентификации через GitHub, приложение должно отобразить ваш профиль.
