# GitHub OAuth поиск пользователей

Небольшое приложение для авторизации через GitHub OAuth и поиска пользователей с использованием GitHub API.

## Внешние зависимости:

- React
- React Router DOM
- Ant Design (antd)
- Axios
- Express (для бэкенда)
- CORS
- dotenv

## Требования

- Node.js и npm установлены на устройстве
